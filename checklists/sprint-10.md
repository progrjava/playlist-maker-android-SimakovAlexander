# Чек-лист Sprint 10: Data Layer & Playlist Logic

## База данных (Room)
- [x] Настроена база данных Room с использованием `AppDatabase`.
- [x] Реализованы сущности:
    - `TrackEntity` — для хранения треков и статуса избранного.
    - `PlaylistEntity` — для хранения информации о плейлистах.
    - `PlaylistTrackCrossRef` — для реализации связи «многие-ко-многим».
- [x] Реализованы DAO:
    - `TracksDao` (избранное, поиск, удаление неиспользуемых треков).
    - `PlaylistsDao` (CRUD для плейлистов).
    - `PlaylistTrackDao` (связи треков и плейлистов).
- [x] Настроена деструктивная миграция (`fallbackToDestructiveMigration`) для удобства разработки.

## Data Layer (Репозитории)
- [x] `TracksRepository`:
    - Поиск треков через сетевой клиент.
    - Работа с избранным (добавление/удаление/получение).
    - Получение трека по ID.
- [x] `PlaylistRepository`:
    - Создание, редактирование и удаление плейлистов.
    - Добавление треков в плейлисты и их удаление.
    - Получение всех плейлистов и треков конкретного плейлиста.
    - Реактивное получение количества треков в плейлисте.
