# Чек-лист самопроверки — Sprint 4

## Описание задач
Этот спринт включает:
- Вёрстка экрана поиска (SearchScreen)
- Вёрстка экрана настроек (SettingsScreen) + шеринги/интенты/ссылка
- Навигация через NavHost/PlaylistHost/Screens
- Компоненты: RowItem, SettingsRowItem, SettingsSwitchRowItem, CustomSwitch и т.д.
- Перенос логики/строк в helpers (`rememberSettingsStrings`, `shareApp`, `contactSupport`, `openUserAgreement`)

---

## Функциональные проверки (manually)

### Навигация
- [ ] Приложение запускается без падений.
- [ ] Из главного экрана при нажатии на «Search» открывается экран Search.
- [ ] Из главного экрана при нажатии на «Settings» открывается экран Settings.
- [ ] Кнопка «Back» в Search и Settings корректно вызывает `navController.popBackStack()` (возврат на Main).
- [ ] Добавление нового экрана в `Screens` + регистрация в `PlaylistHost` не ломает навигацию.

### SearchScreen
- [ ] Поле поиска отображает placeholder «Поиск», когда пусто.
- [ ] Левая иконка — лупа (Icons.Default.Search).
- [ ] Правая иконка — крестик (Icons.Default.Clear), появляется при вводе и очищает текст.
- [ ] Логика поиска оставлена пустой / заглушена (требование задания).

### SettingsScreen
- [ ] Пункт «Поделиться приложением» открывает системный диалог шеринга с текстом из `strings.xml`.
- [ ] Пункт «Написать разработчикам» открывает почтовый клиент с заполненными:
    - получатель = `support_email` из `strings.xml`;
    - тема = `support_subject`;
    - тело = `support_body`.
- [ ] Пункт «Пользовательское соглашение» открывает браузер с ссылкой из `strings.xml`.
- [ ] Все тексты (названия кнопок, email, тема, тело письма, ссылка) вынесены в `strings.xml`.
- [ ] UI строк настроек использует общий компонент (`RowItem` / `SettingsRowItem`), нет дублирования верстки.
- [ ] Переключатель темы (Switch) визуально соответствует дизайну; переключение меняет локальную переменную (`isDarkTheme`) и не падает.
