# Чек-лист самопроверки — Sprint 4

## Описание задач
Этот спринт включает:
- Вёрстка экрана поиска (SearchScreen)
- Вёрстка экрана настроек (SettingsScreen) + шеринги/интенты/ссылка
- Навигация через NavHost/PlaylistHost/Screens
- Компоненты: RowItem, SettingsRowItem, SettingsSwitchRowItem, CustomSwitch и т.д.
- Перенос логики/строк в helpers (`rememberSettingsStrings`, `shareApp`, `contactSupport`, `openUserAgreement`)

---

## Функциональные проверки (manually)

### Навигация
- [x] Приложение запускается без падений.
- [x] Из главного экрана при нажатии на «Search» открывается экран Search.
- [x] Из главного экрана при нажатии на «Settings» открывается экран Settings.
- [x] Кнопка «Back» в Search и Settings корректно вызывает `navController.popBackStack()` (возврат на Main).
- [x] Добавление нового экрана в `Screens` + регистрация в `PlaylistHost` не ломает навигацию.

### SearchScreen
- [x] Поле поиска отображает placeholder «Поиск», когда пусто.
- [x] Левая иконка — лупа (Icons.Default.Search).
- [x] Правая иконка — крестик (Icons.Default.Clear), появляется при вводе и очищает текст.
- [x] Логика поиска оставлена пустой / заглушена (требование задания).

### SettingsScreen
- [x] Пункт «Поделиться приложением» открывает системный диалог шеринга с текстом из `strings.xml`.
- [x] Пункт «Написать разработчикам» открывает почтовый клиент с заполненными:
    - получатель = `support_email` из `strings.xml`;
    - тема = `support_subject`;
    - тело = `support_body`.
- [x] Пункт «Пользовательское соглашение» открывает браузер с ссылкой из `strings.xml`.
- [x] Все тексты (названия кнопок, email, тема, тело письма, ссылка) вынесены в `strings.xml`.
- [x] UI строк настроек использует общий компонент (`RowItem` / `SettingsRowItem`), нет дублирования верстки.
- [x] Переключатель темы (Switch) визуально соответствует дизайну; переключение меняет локальную переменную (`isDarkTheme`) и не падает.
