# Чек-лист Спринт 9

## Задача 1. Реализовать поиск треков
- [ ] Оживлен экран поиска: выполняются настоящие поисковые запросы к iTunes API.
- [ ] Обработка результатов поиска:
    - [ ] **Плейсхолдер (нет результатов):** Отображается заглушка, если ничего не найдено.
    - [ ] **Плейсхолдер (ошибка сервера):** Отображается заглушка с кнопкой «Обновить», если запрос завершился неудачно.
    - [ ] **Нажатие на кнопку «Обновить»:** Выполняется последний неудавшийся запрос.
    - [ ] **Непустой результат:** Отображается список треков.
- [ ] Элементы списка треков содержат:
    - [ ] Обложку (artworkUrl100).
    - [ ] Название трека (trackName).
    - [ ] Имя исполнителя (artistName).
    - [ ] Продолжительность (trackTimeMillis в формате mm:ss).
- [ ] Работа с изображениями:
    - [ ] Используется заглушка, если обложка отсутствует или еще загружается.
- [ ] Кнопка «Очистить поисковый запрос»:
    - [ ] Очищает поле ввода.
    - [ ] Скрывает клавиатуру.
    - [ ] Скрывает список результатов и саму кнопку (x).

## Рефакторинг и внедрение DI (Koin)
- [ ] **Внедрение Dependency Injection:**
    - [ ] Настроен Koin (версия 4.0.0).
    - [ ] Создан класс `App` для инициализации Koin.
    - [ ] Созданы модули: `DataModule` (сеть, репозитории), `ViewModelModule` (все ViewModel).
    - [ ] В Compose-экранах используется `koinViewModel()`.
- [ ] **Архитектурный рефакторинг (MVVM):**
    - [ ] Проведен рефакторинг всех репозиториев (`TracksRepositoryImpl`, `PlaylistsRepositoryImpl`, `SearchHistoryRepositoryImpl`): зависимости передаются через конструктор.
    - [ ] Проведен рефакторинг всех ViewModel (`SearchViewModel`, `PlaylistsViewModel`, `PlaylistViewModel`, `SettingsViewModel`): зависимости передаются через конструктор.
    - [ ] Вся логика из `SettingsScreen` (sharing, support) вынесена в `SettingsViewModel`.
- [ ] **Реорганизация структуры проекта (Слои):**
    - [ ] В `data` выделены пакеты: `network`, `repository`, `mapper`.
    - [ ] В `domain` выделен пакет `api` для интерфейсов.
    - [ ] В `ui` экраны вынесены в подпакеты `screen` внутри соответствующих фич.
