# Чек-лист самопроверки — Sprint 6

## Описание задач
В этом спринте реализован пользовательский интерфейс поиска треков:
- Выполнена связка UI с ранее подготовленной архитектурой 
- Создана `SearchViewModel`, описаны состояния экрана `SearchState`
- Реализован экран поиска на Jetpack Compose 
- Закреплены принципы MVVM и реактивного UI

---

## Функциональные и структурные проверки

### Состояния экрана (SearchState)

- [ ] Создан `sealed class SearchState`.
- [ ] Реализовано первоначальное состояние `Initial`.
- [ ] Реализовано состояние `Searching` для процесса поиска.
- [ ] Реализовано состояние `Success` со списком найденных треков.
- [ ] Реализовано состояние `Fail` с текстом ошибки.

---

### Creator (создание зависимостей)

- [ ] Создан объект `Creator`.
- [ ] В `Creator` реализован метод `getTracksRepository()`.
- [ ] Репозиторий создаётся с использованием `Storage` и `NetworkClient`.
- [ ] `ViewModel` не создаёт зависимости напрямую.

---

### SearchViewModel

- [ ] Создан класс `SearchViewModel`, наследующий `ViewModel`.
- [ ] Используется `MutableStateFlow` для хранения состояния экрана.
- [ ] Состояние экрана доступно через `StateFlow`.
- [ ] Реализована функция `search(query: String)`.
- [ ] При запуске поиска устанавливается состояние `Searching`.
- [ ] При успешном результате устанавливается состояние `Success`.
- [ ] При возникновении ошибки устанавливается состояние `Fail`.
- [ ] Поиск выполняется в `viewModelScope`.
- [ ] Для фоновой работы используется `Dispatchers.IO`.
- [ ] Реализована `ViewModelProvider.Factory` для создания `SearchViewModel`.

---

### UI — SearchScreen (Jetpack Compose)

- [ ] Экран подписан на состояние `ViewModel` через `collectAsState()`.
- [ ] Создан локальный `state` для строки поиска.
- [ ] При изменении текста происходит рекомпозиция UI.
- [ ] По нажатию на иконку поиска вызывается `viewModel.search()`.

---

### Отображение состояний экрана

- [ ] `Initial` — отображается подсказка для пользователя.
- [ ] `Searching` — отображается индикатор загрузки.
- [ ] `Success` — при пустом списке отображается сообщение «Ничего не нашлось», при наличии данных отображается список треков в `LazyColumn`.
- [ ] `Fail` — отображается сообщение об ошибке поиска.

---

### TrackListItem

- [ ] Используется отдельная composable-функция `TrackListItem`.
- [ ] Отображается название трека, исполнитель и длительность.
- [ ] Добавлена иконка трека (`ic_music.png`).

---

### SearchActivity

- [ ] `SearchViewModel` создаётся через `viewModels` с фабрикой.
- [ ] `ViewModel` передаётся в `SearchScreen`.
