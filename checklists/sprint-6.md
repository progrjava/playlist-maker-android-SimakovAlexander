# Чек-лист самопроверки — Sprint 6

## Описание задач
В этом спринте реализован пользовательский интерфейс поиска треков:
- Выполнена связка UI с ранее подготовленной архитектурой 
- Создана `SearchViewModel`, описаны состояния экрана `SearchState`
- Реализован экран поиска на Jetpack Compose 
- Закреплены принципы MVVM и реактивного UI

---

## Функциональные и структурные проверки

### Состояния экрана (SearchState)

- [x] Создан `sealed class SearchState`.
- [x] Реализовано первоначальное состояние `Initial`.
- [x] Реализовано состояние `Searching` для процесса поиска.
- [x] Реализовано состояние `Success` со списком найденных треков.
- [x] Реализовано состояние `Fail` с текстом ошибки.

---

### Creator (создание зависимостей)

- [x] Создан объект `Creator`.
- [x] В `Creator` реализован метод `getTracksRepository()`.
- [x] Репозиторий создаётся с использованием `Storage` и `NetworkClient`.
- [x] `ViewModel` не создаёт зависимости напрямую.

---

### SearchViewModel

- [x] Создан класс `SearchViewModel`, наследующий `ViewModel`.
- [x] Используется `MutableStateFlow` для хранения состояния экрана.
- [x] Состояние экрана доступно через `StateFlow`.
- [x] Реализована функция `search(query: String)`.
- [x] При запуске поиска устанавливается состояние `Searching`.
- [x] При успешном результате устанавливается состояние `Success`.
- [x] При возникновении ошибки устанавливается состояние `Fail`.
- [x] Поиск выполняется в `viewModelScope`.
- [x] Для фоновой работы используется `Dispatchers.IO`.
- [x] Реализована `ViewModelProvider.Factory` для создания `SearchViewModel`.

---

### UI — SearchScreen (Jetpack Compose)

- [x] Экран подписан на состояние `ViewModel` через `collectAsState()`.
- [x] Создан локальный `state` для строки поиска.
- [x] При изменении текста происходит рекомпозиция UI.
- [x] По нажатию на иконку поиска вызывается `viewModel.search()`.

---

### Отображение состояний экрана

- [x] `Initial` — отображается подсказка для пользователя.
- [x] `Searching` — отображается индикатор загрузки.
- [x] `Success` — при пустом списке отображается сообщение «Ничего не нашлось», при наличии данных отображается список треков в `LazyColumn`.
- [x] `Fail` — отображается сообщение об ошибке поиска.

- [x] Отображается название трека, исполнитель и длительность.
