# Чек-лист самопроверки - Sprint 8 — Search, Playlists и Track Details

## Описание спринта

В этом спринте был реализован функционал поиска треков, сохранение истории запросов, экран плейлистов и экран детальной информации о треке.
Также была добавлена mock-база данных для хранения плейлистов, треков и истории поиска.

---

# Чек-лист самопроверки

## Общая работоспособность

* [x] Приложение успешно компилируется.
* [x] Приложение запускается на эмуляторе или физическом устройстве.
* [x] При запуска открывается главный экран приложения.

# Навигация

* [x] На главном экране отображается меню навигации.
* [x] Можно перейти на экран **Songs**.
* [x] Можно перейти на экран **Playlists**.
* [x] Можно перейти на экран **Favorites**.
* [x] Навигация назад работает корректно.

---

# Экран поиска (Songs)

* [x] На экране отображается поисковая строка.
* [x] При вводе текста начинается поиск треков.
* [x] Используется функция `debounce` для задержки запроса.
* [x] Во время поиска отображается **индикатор загрузки**.
* [x] После завершения поиска:

    * [x] отображается список найденных треков
    * [x] либо сообщение **"Ничего не найдено"**.

---

# История поиска

* [x] История поисковых запросов сохраняется.
* [x] При очистке строки поиска отображаются предыдущие запросы.
* [x] При нажатии на запрос из истории он подставляется в строку поиска.

---

# Список треков

* [x] Найденные треки отображаются в списке.
* [x] Каждый элемент списка отображается через `TrackListItem`.
* [x] При нажатии на трек происходит переход на экран **Track Details**.

---

# Экран Track Details

* [x] Отображается подробная информация о треке.
* [x] На экране есть кнопка **Добавить в избранное**.
* [x] На экране есть кнопка **Добавить в плейлист**.

---

# Избранное (Favorites)

* [x] При добавлении трека в избранное меняется его статус `favorite`.
* [x] Экран **Favorites** отображает список избранных треков.
* [x] Удаление из избранного обновляет список.

---

# Экран плейлистов (Playlists)

* [x] Отображается список существующих плейлистов.
* [x] Каждый плейлист отображается через `PlaylistListItem`.

---

# Создание нового плейлиста

* [x] На экране Playlists есть кнопка **FloatingActionButton**.
* [x] При нажатии происходит переход на экран создания плейлиста.
* [x] На экране создания есть поля:

    * [x] название плейлиста
    * [x] описание плейлиста
* [x] Кнопка **Сохранить** создаёт новый плейлист.
* [x] После сохранения плейлист появляется в списке.

---

# Добавление трека в плейлист

* [x] При нажатии **Добавить в плейлист** открывается `ModalBottomSheet`.
* [x] В BottomSheet отображается список плейлистов.
* [x] При выборе плейлиста трек добавляется в него.

# Структура проекта

Проект разделён на основные слои:

```
data
domain
ui
```

### data

Содержит:

* DTO модели
* реализацию репозиториев
* mock базу данных

### domain

Содержит:

* бизнес-модели (`Track`, `Playlist`, `Word`)
* интерфейсы репозиториев

### ui

Содержит:

* экраны приложения
* компоненты Compose
* ViewModel
* навигацию
