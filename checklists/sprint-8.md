# Чек-лист самопроверки - Sprint 8 — Search, Playlists и Track Details

## Описание спринта

В этом спринте был реализован функционал поиска треков, сохранение истории запросов, экран плейлистов и экран детальной информации о треке.
Также была добавлена mock-база данных для хранения плейлистов, треков и истории поиска.

---

# Чек-лист самопроверки

## Общая работоспособность

* [ ] Приложение успешно компилируется.
* [ ] Приложение запускается на эмуляторе или физическом устройстве.
* [ ] При запуске открывается главный экран приложения.

---

# Навигация

* [ ] На главном экране отображается меню навигации.
* [ ] Можно перейти на экран **Songs**.
* [ ] Можно перейти на экран **Playlists**.
* [ ] Можно перейти на экран **Favorites**.
* [ ] Навигация назад работает корректно.

---

# Экран поиска (Songs)

* [ ] На экране отображается поисковая строка.
* [ ] При вводе текста начинается поиск треков.
* [ ] Используется функция `debounce` для задержки запроса.
* [ ] Во время поиска отображается **индикатор загрузки**.
* [ ] После завершения поиска:

    * [ ] отображается список найденных треков
    * [ ] либо сообщение **"Ничего не найдено"**.

---

# История поиска

* [ ] История поисковых запросов сохраняется.
* [ ] При очистке строки поиска отображаются предыдущие запросы.
* [ ] При нажатии на запрос из истории он подставляется в строку поиска.

---

# Список треков

* [ ] Найденные треки отображаются в списке.
* [ ] Каждый элемент списка отображается через `TrackListItem`.
* [ ] При нажатии на трек происходит переход на экран **Track Details**.

---

# Экран Track Details

* [ ] Отображается подробная информация о треке.
* [ ] На экране есть кнопка **Добавить в избранное**.
* [ ] На экране есть кнопка **Добавить в плейлист**.

---

# Избранное (Favorites)

* [ ] При добавлении трека в избранное меняется его статус `favorite`.
* [ ] Экран **Favorites** отображает список избранных треков.
* [ ] Удаление из избранного обновляет список.

---

# Экран плейлистов (Playlists)

* [ ] Отображается список существующих плейлистов.
* [ ] Каждый плейлист отображается через `PlaylistListItem`.

---

# Создание нового плейлиста

* [ ] На экране Playlists есть кнопка **FloatingActionButton**.
* [ ] При нажатии происходит переход на экран создания плейлиста.
* [ ] На экране создания есть поля:

    * [ ] название плейлиста
    * [ ] описание плейлиста
* [ ] Кнопка **Сохранить** создаёт новый плейлист.
* [ ] После сохранения плейлист появляется в списке.

---

# Добавление трека в плейлист

* [ ] При нажатии **Добавить в плейлист** открывается `ModalBottomSheet`.
* [ ] В BottomSheet отображается список плейлистов.
* [ ] При выборе плейлиста трек добавляется в него.

# Структура проекта

Проект разделён на основные слои:

```
data
domain
ui
```

### data

Содержит:

* DTO модели
* реализацию репозиториев
* mock базу данных

### domain

Содержит:

* бизнес-модели (`Track`, `Playlist`, `Word`)
* интерфейсы репозиториев

### ui

Содержит:

* экраны приложения
* компоненты Compose
* ViewModel
* навигацию
